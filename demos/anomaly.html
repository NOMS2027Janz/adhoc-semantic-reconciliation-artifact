Two observability systems on one network must share anomaly understanding with no common model. Agent F is a legacy fault manager — RFC 8632 alarms, syslog, SNMP traps, a vendor X.733 probable-cause dictionary. Agent G is an IETF NMOP agent — the RFC 9940 term ladder, anomaly semantics (concern/confidence, action·reason·trigger), and incident correlation. Act 1 reconciles their models; Act 2 runs a live anomaly through and lets pragmatics decide. Toggle semantics + pragmatics ON/OFF to compare with the legacy pipeline.

About this demo — what you're looking at

The problem moves from configuration to observability. Agent F is the incumbent world: an alarm is a catch-all — event, state, a fixed severity (critical/major/minor/warning) and a probable-cause code, all bundled and hard-coded at emission (RFC 8632 / syslog / SNMP / X.733). Agent G speaks the new IETF NMOP vocabulary, where RFC 9940 separates what legacy collapses — event → anomaly → symptom → fault → alarm(a State) → problem(a State) → cause → incident — and Thomas Graf's anomaly-semantics draft annotates each anomaly with concern and confidence scores, action·reason·trigger, a lifecycle stage, and context (network plane, season, maintenance window).

Act 1 — reconcile the models. The two agents lift their vocabularies, anchor a shared reference to the RFC 9940 ladder, and pin the dangerous ambiguities: a fixed severity label is not a dynamic concern score; a static probable-cause code is not a cause derived by correlation; and the overloaded legacy alarm must be decomposed into the several NMOP concepts it conflates. The headline false cognate: a legacy alarm is not an anomaly — an alarm is a declared undesirable State; an anomaly is a deviation that may be perfectly benign.

Act 2 — the anomaly is the trigger, and pragmatics decide. A rising pre-FEC BER anomaly appears on wavelength λ1. Whether it means anything depends not on the data but on its pragmatics: its significance and confidence (act or watch), its context (a planned maintenance window makes the same deviation benign), and its causal role (a symptom, correlated with an IP-layer symptom into one incident with a probable cause — not two uncorrelated pages). Flip the toggle OFF and you get the legacy result: an alarm storm, a false page during maintenance, and no incident. This is the case Thomas Graf and Brad both flagged — in anomalies, pragmatics carry the meaning.
