Reconciling two independently-authored models of one OTN network. Agent T speaks ONF TAPI; Agent I speaks IETF TEAS/OTN. They plan the attack, lift to ontologies, bind to a thin shared reference lexicon, align in two passes, reconcile the residual, co-refer instances, and validate by round-trip. Toggle the reference lexicon ON/OFF to compare the work — especially the verification work.

About this demo — what you're looking at

This is the fully-cognitive, agent-to-agent case: both sides are competent, interrogable agents. Rather than merge schemas, each agent plans how to attack the reconciliation, lifts its data model to an explicit ontology, and — when the reference is on — binds its concepts to a thin, generic reference lexicon that pins identity only (id, names, a shallow class, a disambiguating definition, one canonical example). Correspondences then fall out by shared reference; only the residual (granularity, scope) is negotiated, and instance co-reference is settled separately, from evidence.

Three things are made explicit. (1) At every stage — how the gap is closed and how it is verified, with a measure. (2) Where the hardest cognition acts: planning, the lift, and the residual reconciliation — watch the cognition meter. (3) The value of the reference lexicon: flip it OFF and the same task costs more conversation and, above all, more verification — see the Work ledger.

Planning is part of the cognitive workflow. The agents do not run a fixed pipeline; they choose the order in which gaps are closed and re-plan when they meet a surprise — the false cognate, a scope gap. The planning beat and its re-plans are shown in the agent windows.
